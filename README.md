## What I build

- **Lead classifier**: scores incoming leads as HOT / WARM / COLD and sends an alert for the hot ones
- **RAG support bot**: answers store FAQs using only the knowledge base
- **Email classifier**: sorts emails into inquiry, complaint, sale or spam
- **Leads CRM on Google Sheets**: saves leads without duplicates and notifies the team

## Stack
